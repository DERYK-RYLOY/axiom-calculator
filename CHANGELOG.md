# Changelog

All notable changes to AXIOM X1 are documented here.

## [1.0.0] — 2026-11-22

### Added
- Skeuomorphic calculator UI: beveled keys, green LCD with scanlines, solar panel, brand plate
- SHIFT/2nd key with secondary function labels, like a physical scientific calculator
- Recursive-descent expression engine with precedence, right-associative powers, factorial, parentheses
- ~50 functions: trig/inverse/hyperbolic, roots, logs, combinatorics, statistics, random, clamp, lerp
- Variables (`x = 5`), `ans`, memory (`mem`), DEG/RAD modes
- Voice input and spoken results
- Function grapher with auto-scaling and zoom
- Unit converter covering 10 categories
- Base converter with bitwise operations
- Fraction display, live preview, clickable history, clipboard support
- Key sounds and haptic feedback
- Four switchable skins with persisted settings
- Installable PWA with offline service worker and full icon set
- Zero-dependency npm CLI (`axiom` / `axiom-calculator`) and smoke test
- Portable C++17 console implementation of the same engine
- Vector artwork (icon, hero, social card, wordmark) and generated screenshots
- Jost (OFL) display font with optional licensed Alro drop-in support
